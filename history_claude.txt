Có thể kết hợp tool này với các skills.md tìm lỗ hổng không?

Có, kết hợp được — và rất hợp lý vì chúng bù trừ cho nhau. Có 3 cách tích hợp.

Kiến trúc: harness vs skill khác nhau ở đâu
Harness này chạy model local qua vòng lặp riêng (rẻ, riêng tư, quét được cả nghìn file, xuất NDJSON).
Skill tìm lỗ hổng (như /security-review, /code-review) chạy bên trong Claude Code — tôi (model lớn) là bộ não, suy luận sâu trên diff/một số file.
→ Kết hợp = local model làm phần thô diện rộng → tôi triage/xác minh phần giá trị cao.

3 cách kết hợp
1. Bọc harness thành một skill (SKILL.md) — bạn gõ /vuln-harness ./src, tôi chạy scanner.py, đọc findings.ndjson, rồi xếp hạng + xác minh + viết báo cáo. Đây là cách "đúng bài" nhất.

2. Pipeline nối tiếp với /security-review (skill built-in trong session này):

scanner.py (local, quét toàn repo) → findings.ndjson
        → tôi lọc top Critical/High → /security-review kiểm chứng sâu diff liên quan
Local model gánh khối lượng lớn; /security-review (dùng tôi) chỉ soi kỹ số ít điểm nóng → tiết kiệm mà vẫn sâu.

3. Nối với skill khác trong session:

/graphify — biến findings.ndjson thành knowledge graph (cụm theo file/CWE/chain) để nhìn toàn cảnh.
/code-review — chạy harness trên diff thay vì cả repo.
So sánh nhanh
Harness (local)	/security-review (Claude)
Phạm vi	Cả repo, nghìn file	Diff / vài file
Chi phí	Rẻ, offline	Tốn token hơn
Chiều sâu	Trung bình (triage)	Cao (reasoning)
Riêng tư	Không rời máy	Gửi lên model
Chiến lược tốt nhất: harness làm first-pass filter toàn repo → /security-review hoặc tôi làm deep-dive trên các finding sống sót sau verify.

Tôi có thể tạo luôn SKILL.md để bạn gõ /vuln-harness <path> là chạy trọn: gọi scanner → đọc NDJSON → triage → (tùy chọn) đẩy top findings sang /security-review và /graphify.

Cách hoạt động
Harness gọi model qua HTTP (không chạy trong Claude Code) nên không invoke skill được. Thay vào đó, skills.py nạp nội dung markdown của SKILL.md rồi bơm vào system prompt của bước tìm lỗ hổng → model local review với chuyên môn của skill đó.

SYSTEM_PROMPT (reviewer gốc)
  + "ADDITIONAL REVIEW GUIDANCE: ### Skill: php-security ...checklist..."
  → gửi kèm mỗi file
Dùng
python scanner.py ./src \
    --skill ./skillpacks \
    --skill ./my-owasp-skill/SKILL.md \
    -o findings.ndjson -v
--skill lặp lại được, nhận file (.md/SKILL.md) hoặc thư mục (nạp SKILL.md + *.md top-level). Hoặc .env: AVH_SKILLS=path1,path2.
Scope theo ngôn ngữ qua frontmatter — skill chỉ áp cho file khớp:
---
name: php-security
extensions: php, phtml     # bỏ trống = áp cho mọi file
---
# checklist POP-chain / injection cho PHP...
File .md thường (không frontmatter) → áp cho mọi file.
Áp dụng cho cả --mode file lẫn --mode chain. Giới hạn kích thước bằng --skill-budget.
